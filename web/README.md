# Aethoria Chronicles — Interfaz Web

Interfaz web pública de la plataforma Aethoria Chronicles 
Database Platform, desarrollada con HTML5 y CSS3.


## ¿Qué empresa representa?

La web representa la plataforma de base de datos oficial del 
videojuego MMORPG ficticio Aethoria Chronicles, un juego de 
fantasía medieval con clases de tanque, DPS y healer.


## Páginas incluidas

- **index.html** → Página de inicio con presentación y acceso rápido
- **clases.html** → Catálogo de clases con sus roles y habilidades
- **items.html** → Catálogo completo de items con tipo y rareza
- **contacto.html** → Formulario de contacto con el equipo de desarrollo


## Cómo visualizarla

Abrir el archivo `index.html` directamente en cualquier navegador web.
No requiere servidor ni instalación adicional.


## Tecnologías usadas

- HTML5 semántico
- CSS3 con Flexbox y Grid
- Google Fonts (Cinzel y Raleway)
- Diseño responsive para móvil y escritorio
