## ¿Qué he aprendido?

Este proyecto me ha servido para entender cómo funciona realmente 
el desarrollo de software. Antes de empezarlo veía cada asignatura 
como algo independiente, pero al tener que combinarlas todas en un 
mismo proyecto me ha quedado claro que forman parte de un proceso 
completo: la base de datos almacena la información, Java la gestiona 
y la web la presenta al usuario.

También he aprendido a usar herramientas que no he utilziado demasiado, como 
Docker para gestionar entornos de base de datos, TablePlus para 
visualizar los datos, o Maven para gestionar las dependencias de Java.


## ¿Qué se me ha dado mejor?

La parte que más he disfrutado y donde me he sentido más cómodo ha 
sido el desarrollo de la interfaz web con HTML y CSS. Ver cómo el 
diseño cobra vida en el navegador es algo que me motiva bastante, 
y creo que es el área en la que más he avanzado durante el curso.


## ¿Qué me ha costado más?

Sin duda la parte más difícil ha sido la conexión JDBC entre Java 
y la base de datos. Configurar Docker, entender cómo funciona la 
conexión y solucionar los errores que iban apareciendo me llevó 
tiempo y tuve que consultar diversas fuentes para poder solucionarlo.
También me costó al principio entender el diseño del diagrama E/R y las relaciones entre entidades.


## ¿Qué mejoraría?

Si tuviera más tiempo y conocimientos mejoraría varias cosas. 
Por un lado conectaría la web directamente a la base de datos 
para que el contenido se cargue de forma dinámica. Por otro lado 
añadiría la operación de modificar datos que falta en la aplicación 
Java. Y a largo plazo me gustaría implementar la idea original del 
proyecto: un sistema de IA que actualice automáticamente la base 
de datos cuando los desarrolladores suban nueva documentación.
Ademas de hacerla de manera que pueda ser usada por diferentes 
juegos y no solo centrado en el inventado para este trabajo.


## Conclusión personal

Ha sido un proyecto exigente para ser de primero,
en muchas ocasiones tenia que dar pasos hacia atrás para
no quedarme atascado, pero también muy completo. 
Me ha dado una visión real de lo que es desarrollar 
una aplicación desde cero.
