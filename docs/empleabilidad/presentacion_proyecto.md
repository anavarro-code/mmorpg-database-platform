# Presentación del Proyecto
## Aethoria Chronicles Database Platform


## ¿Qué es?

Aethoria Chronicles Database Platform es una plataforma web de base 
de datos diseñada para centralizar y organizar toda la información 
relevante de un videojuego MMORPG de fantasía medieval ficticio 
llamado Aethoria Chronicles.


## ¿Qué problema resuelve?

En la mayoría de los MMORPGs la información del juego está dispersa 
entre foros, wikis desactualizadas y documentación oficial poco 
accesible. Esta plataforma centraliza toda esa información en un 
único lugar, garantizando que el contenido sea siempre oficial 
y esté actualizado.


## ¿Para quién está pensado?

- **Jugadores** que quieren consultar información sobre clases, 
  habilidades e items del juego

- **Desarrolladores** del juego que necesitan gestionar y mantener 
  actualizado el contenido

- **Comunidad en general** interesada en conocer el juego


## ¿Qué tecnologías utiliza?

| Tecnología | Uso en el proyecto |

| HTML5 + CSS3 | Interfaz web pública |
| Java + JDBC | Aplicación de gestión interna |
| MySQL | Base de datos del juego |
| Docker | Contenedor de MySQL |
| Maven | Gestión de dependencias Java |
| GitHub | Control de versiones |


## ¿Qué he aprendido gracias a este proyecto?

- A diseñar y construir una base de datos relacional desde cero
- A conectar una aplicación Java con una base de datos mediante JDBC
- A maquetar una interfaz web completa con HTML y CSS
- A organizar un proyecto profesional en GitHub con commits progresivos
- A entender cómo se conectan entre sí los diferentes módulos del curso
- A trabajar con Docker para gestionar entornos de desarrollo
