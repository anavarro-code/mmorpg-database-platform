## Sobre mí

Soy estudiante de primer curso del Grado Superior de Desarrollo de 
Aplicaciones Web (DAW) en Prometeo by The Power. Me interesa el 
desarrollo web y la programación orientada a objetos, y estoy 
aprendiendo a combinar diferentes tecnologías para crear proyectos 
completos y funcionales.

Me gustan especialmente los proyectos que tienen un componente creativo,
como este, donde he podido combinar mi interés por los videojuegos con 
el aprendizaje técnico del curso.


## Qué estoy aprendiendo

- HTML y CSS para el desarrollo de interfaces web
- Java para programación orientada a objetos
- MySQL para el diseño y gestión de bases de datos
- Git y GitHub para el control de versiones
- Entornos de desarrollo como IntelliJ IDEA y VS Code


## Qué tipo de proyectos me interesan

Me interesan los proyectos que combinan frontend y backend, 
especialmente aquellos relacionados con plataformas web, 
gestión de datos y aplicaciones con base de datos. 
También me llama la atención el desarrollo de herramientas 
útiles para comunidades, como este proyecto de base de datos 
para videojuegos.


## En qué me gustaría especializarme

A largo plazo me gustaría especializarme en algo relacionado con la ciberseguridad, ya que me parece un mundo muy completo con muchas cosas interesantes que aprender. Tambien me llama la atención el desarrollo de tecnologias apoyado por IA, ya que gracias a esta se obtiene un aumento enorme en cuanto a productividad.


## Qué me motiva

Me motiva ver cómo un proyecto crece desde cero hasta convertirse en 
algo funcional y visual. Durante este proyecto he podido comprobar 
cómo todas las piezas encajan: el diseño web, la base de datos y 
la programación forman parte de un mismo proceso, y eso es lo que 
más me ha gustado del desarrollo de software.
